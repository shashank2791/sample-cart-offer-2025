This document provides a comprehensive overview of all test scenarios and test 
cases implemented for the Cart Application API endpoint only. Based on requirement 
changes, testing is now focused exclusively on POST /api/v1/cart/apply_offer.

SYSTEM OVERVIEW:
- Customers are divided into 3 segments: P1, P2, P3
- Offers can be FLATX (flat amount off) or PERCENT (percentage off)
- Cart application API applies pre-created offers to user carts
- Offers are applied based on user segment matching via mock service

API ENDPOINT TESTED:
- POST /api/v1/cart/apply_offer - Apply offers to cart with E2E integration

TESTING SCOPE:

    SCENARIO: Complete E2E FLATX offer workflow with real API calls
    E2E WORKFLOW: Validate user segment → Create offer → Apply to cart → Validate all responses
    API CALLS: GET /user_segment → POST /offer → POST /cart/apply_offer
    SETUP: User ID=1 (P1), Restaurant ID=101, FLATX ₹50 off for P1 segment
    REQUEST: Cart Value=₹200, User ID=1 (P1), Restaurant ID=101
    EXPECTED: User segment=P1, Offer creation=success, Final cart value = ₹150
    METHOD: testFlatXOfferApplication()
